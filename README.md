# bank-reconciliation 銀行匯款對帳

**把官網後台匯出的「匯款訂單」CSV，整理進銀行匯款對帳總表（xlsx）。**

## 功能流程

| 步驟 | 說明 |
|------|------|
| **Step 1** | 讀取 CSV（自動判斷 cp950 / big5 / utf-8 編碼），刪除全空白列 |
| **Step 2** | 逐列對應成總表 7 欄：交易日、存款金額、摘要、備註、部門、網站訂單編號、賣家備註 |
| **Step 3** | 摘要智慧修正：賣家備註若寫「正確後5碼」，用正確碼覆蓋轉帳後五碼 |
| **Step 4** | 接續寫入既有總表最後一列之後（表頭與既有資料保留） |
| **Step 5** | 格式化：交易日置中＋日期格式、存款金額靠右＋千分位、摘要文字格式（保留前導零） |

## 安裝依賴

```bash
pip install openpyxl
```

## 使用方式

```bash
python bank_recon.py <匯款訂單.csv> [--total 對帳總表.xlsx] [--dept 電圖部] [--overwrite]
```

### 參數

| 參數 | 說明 |
|------|------|
| `匯款訂單.csv` | 官網匯出的匯款訂單 CSV（必填） |
| `--total` | 對帳總表檔名（預設 `銀行匯款對帳資料-總表.xlsx`），不存在會自動建立 |
| `--dept` | 部門固定值（預設 `電圖部`） |
| `--overwrite` | 清空總表既有資料列後重寫（只保留表頭） |

### 範例

```bash
python bank_recon.py "E-0922.csv"
```

```
來源: E-0922.csv（編碼 cp950）
寫入 20 筆 → 銀行匯款對帳資料-總表.xlsx（第 3~22 列）
摘要以「正確後5碼」覆蓋: 2 筆
```

## 欄位對應

| 總表欄位 | 來源／規則 |
|----------|-----------|
| 交易日 | 匯款日期（`yyyy/mm/dd`） |
| 存款金額 | 匯款金額（`#,##0`） |
| 摘要 | 轉帳後五碼；賣家備註含「正確後5碼」時改用該 5 碼（文字格式） |
| 備註 | 匯款銀行 |
| 部門 | 固定值（預設 `電圖部`） |
| 網站訂單編號 | 訂單編號 |
| 賣家備註 | 賣家備註原文 |

## 注意

- 來源 CSV **不要用 Excel 開啟後另存**，12 位數單號會被轉成科學記號而遺失末碼。
- 摘要一律存成**文字格式**，避免 `00780` 這類前導零被吃掉。
- 總表可累積，每次執行接在最後一列之後。
